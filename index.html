    Send items to Apple Notes

    Create one Shortcut that gets the clipboard and appends it to your chosen note. Nibble copies the item for you when you tap +.

    In the Shortcuts app:

    1. Create a shortcut with the same name you enter below.
    2. Add a Get Clipboard action.
    3. Add an Apple Notes action that appends the clipboard result to your grocery note.
    4. Do not add Ask for Input; the item is already copied.
